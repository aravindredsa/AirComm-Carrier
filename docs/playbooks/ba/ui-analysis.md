# UI Analysis

## Purpose
Guide users through producing a complete UI analysis from source documents for downstream Dev, QA, and Product consumption.

## Inputs
- attached UI and requirement source documents
- template `templates/ba/ui-analysis-template.md`

## Recommended Workflow
1. Confirm all source files are available and readable.
2. Run `/ba-ui-analysis`.
3. Validate exhaustive extraction of field rules, validations, conditions, and workflow behavior.
4. Confirm there are no placeholders and no omitted sections.
5. Save final artifacts to `artifacts/ui-analysis/`.

## Output
- `artifacts/ui-analysis/UI_Analysis_<YYYY-MM-DD>.md`
- `artifacts/ui-analysis/UI_Analysis_<YYYY-MM-DD>.docx`

## Notes
- Expand documented detail fully instead of summarizing when source details exist.
