# Evaluate Output Quality

## Purpose
Guide users through assessing a generated output for quality, completeness, and standards alignment.

## Inputs
- Target output document or artifact
- Applicable standards resolved through `config/standards-resolution-policy.json`, `config/client-profiles.json`, and `config/standards-catalog.json`

## Recommended Workflow
1. Identify the artifact to review and the standards that apply.
2. Run `/evaluate-output-quality`.
3. Review findings, scores, and recommendations.
4. Capture follow-up actions for any gaps that were found.

## Output
- Quality findings and recommendations
- Scored assessment aligned to workspace standards
