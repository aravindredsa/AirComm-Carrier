# Generate Automation Tests

## Purpose
Generate test automation code (resolver-selected automation frameworks) for a given feature or module. This prompt produces production-ready test scripts with page objects, test fixtures, and assertions following active client overlay testing standards.

## Quick Start

## Input

Trigger the automation tests generation prompt in Copilot Chat:

```
/generate-automation-tests
```

Or provide specific context:

```
Generate resolver-selected automation test for the login flow, including page object model and test fixtures
```

## Typical Flow

1. Prepare Context
2. Specify Framework
3. Run Prompt
4. Review Output
5. Integrate and Customize
6. Run Tests
