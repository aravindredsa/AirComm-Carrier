# Generate Functional Test Cases

## Purpose
Guide users through generating requirement-driven functional test cases across related modules and workflows.

## Inputs
- Feature name
- Acceptance criteria
- Business rules and workflow context

## Recommended Workflow
1. Gather the feature requirements and in-scope workflow.
2. Run `/generate-functional-test-cases`.
3. Review the generated cases for requirement traceability and edge coverage.
4. Save or refine the final cases before test execution.

## Output
- Functional test cases saved to `test-assets/manual/functional/`
