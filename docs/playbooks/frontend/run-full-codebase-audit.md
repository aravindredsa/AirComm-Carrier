# Run Full Codebase Audit

## Purpose
Guide users through generating a full repository audit report.

## Recommended Workflow
1. Run `/audit-fullcodebase`.
2. Perform discovery and scoring across the entire repository.
3. Use `templates/audit-fullcodebase-report-template.md` for the final report structure.
4. Save final output in `reports/audits/full-codebase/`.

## Output
Store final report in `reports/audits/full-codebase/`
