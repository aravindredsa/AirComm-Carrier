# Generate Evaluation Matrix Playbook

## Purpose
Guide users through creating an evaluation matrix for a feature, workflow, or candidate solution.

## Use This Playbook When
- comparing feature options or implementation approaches
- defining weighted evaluation criteria for a business workflow
- preparing structured review criteria before solution selection

## Inputs
- feature or workflow scope
- evaluation criteria candidates
- stakeholders or decision-makers
- template in `templates/evaluation-matrix-template.md`

## Recommended Workflow
1. Define the decision scope and options being evaluated.
2. Run `/generate-evaluation-matrix`.
3. Review criteria, scoring dimensions, and weighting for completeness.
4. Adjust wording for stakeholder clarity if needed.
5. Save the approved matrix in the appropriate artifact or report location.

## Quality Checklist
- Criteria are measurable and unambiguous.
- Weights reflect real decision priorities.
- Scoring guidance is consistent across options.
- The final matrix is easy for stakeholders to review.

## Expected Output
- One evaluation matrix in markdown using the standard template

## Notes
- Use this playbook when evaluation consistency matters more than freeform discussion.
