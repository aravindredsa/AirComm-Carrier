# AI Workspace Agent Guide

## Purpose
This file explains how the AI enablement workspace is organized and how prompts, skills, templates, artifacts, and reports fit together.

## Core Model
- Prompts = runnable tasks
- Skills = task logic
- Templates = output structure
- Artifacts = generated work
- Reports = final summaries/results

## Primary Folders
- `.github/prompts/` → runnable prompt files
- `docs/standards/` → standards and conventions
- `docs/playbooks/` → step-by-step workflow guides
- `docs/architecture/` → framework explanations
- `docs/references/` → quick lookup content
- `.github/skills/` → reusable task methods
- `templates/` → standard output formats
- `artifacts/` → generated working outputs
- `reports/` → audit/evaluation/execution results

## Operating Principle
Use prompts to execute work, standards to enforce consistency, playbooks to guide humans, and templates to keep outputs uniform.
